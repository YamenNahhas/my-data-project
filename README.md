# 📊 Data-Science-Portfolio: Biologie, Medizin & Pharmazie

Dieses Repository enthält meine Data-Analytics-Projekte mit Python und SQL. Ich bin Apotheker (Approbation 2021) und habe 2025 eine Weiterbildung zum Data Analyst absolviert. Die Projekte verbinden mein pharmazeutisches Fachwissen mit datenbasierten Methoden.

## 🧰 Technologien

Python · Pandas · SQL · Matplotlib · Jupyter Notebooks · Git · uv

## 🗂️ Projekte

| Projekt | Inhalt | Methoden |
|---|---|---|
| **Diabetes dataset** | Kaggle-Datensatz mit 100.000 Patienten und 32 Merkmalen (Demografie, Lebensstil, Krankengeschichte, klinische Messwerte). Ziel: die metabolische Heterogenität von Diabetes besser verstehen und klassische Grenzwerte (z. B. HbA1c ≥ 6,5 %) durch probabilistische und clusterbasierte Erkenntnisse ergänzen. | Cleaning, EDA, Gruppierung, lineare und logistische Regression, Klassifikation, Clustering, Visualisierung |
| **DNA classification** | Menschliche DNA-Sequenzen, gruppiert nach Genfamilien. Ziel: Klassen mit besonders deutlichem Merkmalsprofil erkennen und biologische Varianz clustern. | Cleaning, EDA, Duplikatbehandlung, Klassifikation, Clustering, PCA |
| **Airline Data Analysis Using SQL** | Analyse von Flugdaten mit SQL-Abfragen. | SQL |
| **Bacteria Dataset** | Analyse eines Bakterien-Datensatzes. | Python, Pandas |
| **Protein structure prediction** | Vorhersage von Proteinstrukturen. | Python |
| **pharma-sales-data** | Analyse von Pharma-Verkaufsdaten. | Python, Pandas, Matplotlib |
