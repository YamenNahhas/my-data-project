> Hier geht es um diabetes dataset von kaggle. Dieses Dataset besteht aus 100.000 Zeilen und 32 Spalten inklusiv demographics, lifestyle, medical history und clinical meaurements.

## 📊 Projektübersicht

**Problemstellung:** 
This dataset contains human DNA sequences grouped according to their gene families. The goal to detect which class has a very strong and distinct feature profile and which features are important by classification. 

**Ziel:** 
DNA clustering, DNA classification, detection of class which has a very strong and distinct feature profile. Clustering and recognition of biological varianz.

**Methoden:** 
Cleaning, Exploratory Data Analysis(EDA), Deal with duplicaties, Classification, Clustering, Visualisierung with PCA
